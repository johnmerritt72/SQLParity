# What's New in SQLParity 1.4.4

A small quality-of-life improvement for the Generate Script flow.

## ✨ Added

### Auto-open the generated script in SSMS
After **Generate Script** writes the .sql file, SQLParity now opens it as a new SQL query tab in the active SSMS window — no more switching to Explorer to find the file you just saved.

Controlled by a new toggle:

> Tools → Options → SQLParity → General → **Script Output → Open Script After Generate**

Default is **on**. Turn it off to keep the previous behavior (file saved, no tab opened).

The existing "Script saved to *path*" summary dialog still appears either way with the change and destructive counts, so you don't lose the at-a-glance summary. If for some reason the open call fails, the save still succeeded and the file is on disk — the failure won't bury the success.

## 📦 Install

Close SSMS, then run the SSMS 22 installer (elevated):

```powershell
& "C:\Program Files\Microsoft SQL Server Management Studio 22\Release\Common7\IDE\VSIXInstaller.exe" `
    /instanceIds:919b8d66 `
    "SQLParity.Vsix.vsix"
```
